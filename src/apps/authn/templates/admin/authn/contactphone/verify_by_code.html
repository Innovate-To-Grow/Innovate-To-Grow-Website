Verify by SMS code

{{ contact.get_formatted_number }} on {{ contact.member }} · {{ status }}

A verified number can sign in to this account with a texted code, so it is verified only when the member shows they hold the phone. Never mark it verified on someone's word alone.

  1. Talk to the member: in person, or on a call to them at a contact you already trust.
  2. Send the code. It goes to this number only, works for 10 minutes and allows 5 tries.
  3. Ask the member to read the code to you, and enter it below.

If they never get it, the number is probably wrong: correct it with them (a changed number starts unverified) and send a new code. A member who can sign in by email can also verify the number themselves on their account page.
