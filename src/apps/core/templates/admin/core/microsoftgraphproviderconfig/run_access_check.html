  • the application roles the token claims, against the approval (GRAPH_APPROVED_APPLICATION_ROLES); a broader role that covers an approved one and is listed in GRAPH_ACCEPTED_BROADER_APPLICATION_ROLES (Mail.ReadWrite, as OIT granted it) is accepted and noted, and any other extra role needs an InfoSec exception reference;
  • each mailbox with read permission: its Inbox, its newest message and the start of that message (nothing is kept);
  • each mailbox with send permission: a probe email to itself (a copy stays in its Sent Items);
  • the deny mailbox {{ original.access_check_deny_mailbox|default:"(not set)" }}: reading it, sending as it, and sending with it as the From address must all be refused. Those sends are addressed to the I2G mailbox and keep no Sent Items copy.
