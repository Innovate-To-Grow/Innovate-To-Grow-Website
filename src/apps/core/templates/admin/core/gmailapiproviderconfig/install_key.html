Paste or upload the JSON key file Google Cloud created for the service account. It is checked in memory (a service-account key, an RSA key of the required size, Google's token endpoint), then the site asks Google for a gmail.send token as {{ from_email }} with it. Only then is the key stored in the credential store (AWS Secrets Manager in production) and pinned here. The old key's stored version is kept, and it stays in use until this succeeds.

A key that replaces one of the same service account, or that goes on an active configuration, must already get a token. A first key may also be installed while the Workspace admin is still authorizing the client ID (that can take up to 24 hours). Every install clears the access-check evidence.
