The site checks what Google lets the installed key do, with fresh tokens that are never cached, and records the evidence email needs to switch to the Gmail API:

  • the pinned key reads from the credential store and matches the recorded key ID and service account;
  • Google issues a gmail.send token for each account on the allow-list;
  • an address off the list is refused by the site before any request (Google is not asked: it would grant it);
  • each broader scope (full Gmail, read, modify, Drive, Calendar, Cloud, Directory, …) is refused by Google;
  • optionally, a probe email from each account to itself (it stays in that account's Sent folder).

Google-side per-user restriction is not available for domain-wide delegation: the allow-list is the per-user control, and it does not bind anyone who holds the key.
