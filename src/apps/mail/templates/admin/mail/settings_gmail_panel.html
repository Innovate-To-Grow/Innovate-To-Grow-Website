Gmail API Provider

Sends as a Google Workspace account through a service account with domain-wide delegation (gmail.send only). This page only selects it: the key and the account allow-list are managed on the Gmail API configuration's own page, by superusers. The From email must be on the allow-list, and email switches to the Gmail API only after a passed access check for the installed key. Gmail keeps a copy of everything it sends in the account's Sent folder, so that folder is shown to superusers only. How fast it sends and its daily limits are set under Mail → Delivery Rates.
