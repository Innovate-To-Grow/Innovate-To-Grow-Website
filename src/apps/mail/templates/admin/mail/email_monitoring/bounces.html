A report is matched exactly when it quotes the original Message-ID; otherwise only when exactly one email went to that recipient with that subject shortly before (inferred). The category comes from the SMTP reply code and the enhanced status code; the diagnostic text only refines a generic code. Only "Address does not exist" and "Mailbox disabled" are evidence against an address; a temporary failure (a connection timeout, a DNS failure, a delivery that expired after retries) never is. If a diagnostic looks misread, note its code and text: the phrase lists are tuned from these reports.
