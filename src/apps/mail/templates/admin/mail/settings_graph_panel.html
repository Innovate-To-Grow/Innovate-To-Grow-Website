Microsoft Graph Provider

Sends (and, with read permission, reads the admin inbox) through Outlook / Exchange Online with an Entra app. This page only selects it: the configuration, its mailbox scope and its certificate are managed on the Microsoft Graph configuration's own admin page. The sender mailbox and the From email must both be in the mailbox scope with send permission. Exchange Online allows about 30 messages per minute per mailbox.
